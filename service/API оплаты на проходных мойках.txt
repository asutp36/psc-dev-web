API для оплаты на терминалах проходных моек ЭКО приложением

Оплата происходит в 2 этапа:
	1. запрос суммы к оплате на терминале
		endpoint на терминалах
			@app.route("/api/gate/pay/amount/get", methods=["GET"])
				входные параметры
					TerminalCode - код терминала
					ClientPhone - номер телефона клиента
				выходной результат
					amount - сумма к оплате в рублях
				коды возврата
					200 - успешный результат, возвращается сумма
					406 - оплата невозможна, сумма оплаты 0, терминал не ждёт оплаты
					500 - ошибки на терминале
					
			
	2. оплата через мобильное приложение
		endpoint на терминалах
			@app.route("/api/gate/pay/amount/increase/mobapp", methods=["POST"])
				входные параметры
					TerminalCode - код терминала
					ClientPhone - номер телефона клиента
					Amount - оплачиваемая сумма
				выходной результат
					amount - сумма к оплате в рублях
				коды возврата
					200 - успешный результат, возвращается сумма
					406 - оплата невозможна, сумма оплаты 0, терминал не ждёт оплаты
					500 - ошибки на терминале


Для проходных моек оплату можно делать на платёжных терминалах и на выездных терминалах.
В 1 очередь подключаем оплату на платёжных терминалах.

Для получения ip адресов используется база GateWash, таблица Device

use GateWash;

select IpAddress from Device d join DeviceTypes dt on dt.IDDeviceType = d.IDDeviceType and dt.Code in ('pay', 'typedExit') where d.Code = 'входной_параметр_Terminal_Code'

Далее по полученному ip вызывается соответствующий endpoint с трансляцией параметров, кроме TerminalCode.
